Zakres próbki

Puste wysepki do 3 pól są wypełniane brukiem; większa zieleń i podwórka pozostają. Nowe grafiki zastępują tylko zgodne moduły 2×2. Widok siatki pokazuje komórki bazowe. Mosty, tunele i inne poziomy są pominięte. Źródło nadal nie zawiera ID węzłów OSM.
