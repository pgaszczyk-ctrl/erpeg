# Erpeg: notes for Claude

- The owner does not program. They describe features in Polish; reply in Polish, avoid jargon, and verify changes yourself (build plus a Playwright screenshot/check) before reporting.
- Stack: Phaser 4 + TypeScript + Vite. `npm run build` runs a typecheck and the build. The Phaser 4 API differs from v3 (e.g. `setTintMode` instead of `setTintFill`); the bundled guides live in `node_modules/phaser/skills/`.
- The game is played on the real map of Lublin. `data/lublin-osm.geojsonseq.gz` is an OpenStreetMap extract made by `scripts/fetch-osm.sh`. Refresh it with the "Fetch Lublin map data" workflow (workflow_dispatch); the sandbox cannot reach OSM servers. `scripts/build-map.mjs` turns it into `public/map/lublin.json` (gitignored) before dev/build.
- Layout: `src/content/fabula.ts` holds the missions and enemy spots, written in Polish by address; the owner dictates these. `src/map/CityMap.ts` handles collisions, address lookup and spawn. `src/map/MapRenderer.ts` draws the map in chunks. `src/quests.ts` holds the logged-in session and mission progress. `src/api.ts` talks to the server. `src/ui/menu.ts` is the HTML start screen (new character, load, memorial). `src/art.ts` holds the placeholder sprites. `src/objects/` holds the player and enemies (plain sprites with `vel`, moved by GameScene with map collisions). `src/scenes/` holds Boot (loads the map), Game and UI (HUD, dialogs, goal arrow, touch controls).
- When adding missions, check that the addresses exist in the map data (the game also shows a toast listing any it cannot find).
- Mobile first: integer camera zoom. All input (touch, keyboard, mouse click) is handled natively in `src/controls.ts`; Phaser input for touch and keyboard is disabled because its pointer and key state got stuck on real devices. UIScene only draws the controls. Test at phone viewport too.
- Scale: `PX_PER_M` (1.6) in CityMap. Stored positions carry their scale (players.map_scale, snapshot `s`, fog `s`) and are converted on load.
- Fog of war: `src/map/Fog.ts`. Vision is a raycast cone blocked by buildings. Explored cells are saved in the save as `fog`. Enemies and pickups outside the vision are hidden. The map screen is `src/ui/minimap.ts` (🗺 button or M).
- Shops (Biedronka, Lidl, Lewiatan; OSM has no Delikatesy Centrum inside the city) and schools come from OSM POIs (`pois` in the map JSON, `CityMap.places`). Shops sell swords and schools teach sword fighting; prices and stats live in `src/content/sklepy.ts`. Sword and skill are stored in the save. Entering a shop or school is a save point too. Separate sidewalk/crossing ways are dropped in build-map; car roads are drawn with a stone sidewalk edge.
- Churches, offices and police stations give random missions (`src/content/zlecenia.ts`, `missionForPlace` in quests.ts). The seed is place id + a per-login nonce, so each login brings a new one. Taken, unfinished ones are kept in the save as `gen`. Police gives bounties: a bandit hidden near a spot (`szukaj`: the arrow shows only the area) or a big slime. Hospitals heal for free. Enemy kinds are in `ENEMY_KINDS` (objects/Slime.ts).
- Map look: build-map drops roofs/shelters and tiny buildings (<25 m² without address), grows every building by 1.2 m, merges touching ones and cuts every road out as wide as it is drawn (clipper-lib, ~5 min; skipped when the JSON is newer than the data and the script). All roads, pavements and paths are drawn as one track: every outline first, then every fill in one colour.
- `src/scenes/Ambient.ts`: fruit trees on green areas (deterministic per area, created near the hero; swinging drops one fruit, 2–5 per tree, regrow each login; fruit sold in shops, prices in content/sklepy.ts) and street enemies (0–20 per 1×1 km cell by narrow-street length, in groups; a chasing enemy pulls in its neighbours; enemies far from the hero sleep).
- Headless Chromium frame times vary a lot between containers; compare against an older build on the same machine before calling something a regression.
- Items and skills: `src/content/przedmioty.ts` (catalogue: weapon in hand, ranged bow or magic item, armour, helmet, boots; skill curve 100 × 1.5^n up to level 10). `src/inventory.ts` holds `gear`: equip, a 5-slot bag (fruit stacks to 99), skill practice points and the magic flag. Saved as equip/bag/skills/magic; old sword/swordSkill/fruits saves are converted in loadGear. A tap is a melee swing; holding over 250 ms (or dragging) aims and releasing shoots (`hold`/`consumeRelease` in controls.ts, `updateRanged`/`updateShots` in GameScene). Hits on enemies, trees and training stations (dummy/target/crystal on sports pitches, `Training` in Ambient.ts) give practice. Libraries teach magic and sell magic items; schools sell lessons (+practice). Character sheet: `src/ui/character.ts` (👤 or C).
- Admin panel: `admin.html` + `src/admin/admin.ts` (no Phaser). Auth: admin password checked by `_admin_ok` (bcrypt in `admin_config`, 5 bad tries lock 10 min); RPCs `admin_overview`, `admin_save_mission`, `admin_save_code`, `admin_set_key`. Missions made there live in table `missions` (same fields as `Misja`), are loaded at login by `game_content` (`loadContent` in quests.ts, 5 s timeout) and merged with MISJE. Zadanie typ `brak` = just a place.
- Secret codes: table `secret_codes` (code, mission_id, reward item, max_uses) + `redemptions` (once per character). In a mission dialog whose id has an active code the game adds "🤫 Psst, mam tajemne hasło" (`missionDialog`/`tellSecret` in GameScene, prompt in `src/ui/prompt.ts`), RPC `redeem_code` (10 bad tries per hour). Mythic items in przedmioty.ts have `efekt`: `swiatlo` (vision ×SWIATLO, glow) and `pioruny` (auto lightning, PIORUNY).
- Death and resurrection: `die` stores death_x/y/scale and stats and adds a row to `deaths` (the memorial board reads `deaths`). The start screen shows a dead character's ghost on a still map (`ghostMap` in menu.ts, `drawCity` in `src/map/drawCity.ts`). `resurrect` is free the first time; later ones answer "1 €, payments soon".
- Stats in the save (`stats`: m walked, kills per kind, earned, spent, fruit, missions, codes), counted via `earn`/`spend` in quests.ts. Eating 20 fruit heals one heart (character sheet). Practice hits show a skill bar (UIScene `showPractice`).
- Home: a house at the start point (TEX.home). Coming back to it heals fully, saves and offers the chest (`src/ui/chest.ts`): 10×10 slots + money, saved as `chest` {slots, coins}; drag with pointer events or tap to move between chest and backpack.
- Riddle-givers ("mądrale", `src/scenes/Npcs.ts`, content in `src/content/zagadki.ts`): every day about one in 4 schools/churches gets one on a street ~500 m away (seeded by date). One riddle a day each, one try, picked for the player's age (players.age, asked at creation, default 7) and the NPC's difficulty (−1/0/+1 level); half are generated sums. Answers kept in the save as `riddles` {npcId: day}.
- Languages: `src/i18n.ts` picks Polish or English from the device (`?lang=pl|en` forces it); two-language texts are `{ pl, en }` read with `tr()`, or inline `tx(pl, en)`. So far only the fixed characters are bilingual; the rest of the game is still Polish.
- Fixed characters (`src/content/postacie.ts`, `src/scenes/FixedNpcs.ts`, they stroll along their street lines): the dog on Guliwera/Cyda (piggy in bushes near the playground between them, state `missions['npc-pies']`, +100 EXP once), Sister Margo on Orlanda (riddle on the 3rd talk of the day, then 2 manners riddles, 10 EXP each), Grandpa Marek or Grandma Iwonka (by day) at Jana Śnieżyńskiego 19–27 (one science riddle a day, 50 EXP). Daily counters in the save as `daily`.
- Hero look: `src/look.ts` draws the player's hero pixel by pixel (16×20 frames: head shape, build, outfit, hairstyle, skin/hair/top/bottom colours, plus worn helmet/headwear, armour and boots). Chosen with sliders at creation (preview in menu.ts), saved as `save.look` (create_character `p_look`). In the game the texture is `hero-me` with anims `me-walk-*` (`makePlayerTexture` in art.ts), redrawn when worn gear changes (`refreshLook`). NPCs still use the default `hero` texture. Headwear items: kapelusz (Robin Hood), skórzany/żelazny hełm, czapka_maga (library), korona (only via codes/rewards); shops offer every headwear not owned.
- Home: the nearest real building to the start point (`setUpHome`), a small house icon on its roof; a sword swing that lands on it opens the home (walking in does not). No enemies within `HOME_SAFE_M` (40 m) of the start: they vanish (`clearHomeArea`, mission enemies excepted).
- Roads: build-map turns major/medium/minor roads into `paved` areas (merged, gaps under 12 m between them closed, buildings cut out), drawn with a cobblestone pattern over the earthen tracks; thinner roads and paths stay earthen. Roundabouts (`junction=roundabout`) get a `merchant` POI: a cart on the ring that works as a shop.
- Fog: a building hit by a vision ray is shown whole (roof and walls) and marked explored (`markBuilding`).
- Touch: the joystick is fixed (bottom left, with arrows); only a touch on it steers, speed grows with the distance from the centre; it blinks at the start and after ~9 s without moving (`joyHome`/`activity` in controls.ts).
- Sharing the code: "📤 Wyślij sobie" uses the phone's share menu (Web Share API, with the QR picture where allowed), falling back to a wa.me link.
- `window.__game` is exposed for debugging and automated browser checks.
- Server: Supabase project `erpeg` (id iiffchuhrhsjjgmstypx). Table `players` has RLS on and no policies; all access goes through SECURITY DEFINER RPCs (create_character, login, save_game, heartbeat, logout, die, memorial). The sandbox cannot reach supabase.co, so test RPCs with SQL via the Supabase MCP and test the client with Playwright `route` mocks.
- Login: name + an 8-character code (column `idik`, no password). `src/ui/codeCard.ts` shows the code, a QR code (a link `#postac=…&kod=…` that loads the character), a picture download and "send by e-mail". Old characters (6-char IDIK + password) log in once with the password and get a new code (`new_code`). E-mail goes through the Edge Function `send-code` (source in `supabase/functions/send-code`, deployed with verify_jwt off; auth is the session token; limits in the SQL function `_email_request`: 3 per character per day, 5 per address, 90 in total). It needs the `RESEND_API_KEY` secret (optional `MAIL_FROM`, `GAME_URL`); without it the function answers that e-mail is not enabled yet.
- Rules: Saves happen only when entering a mission building or finishing a mission. Death is final and goes to the memorial board. Closing the tab without "Wyjdź" means the next login replays the last heartbeat snapshot: the character is stuck for 10 s among the enemies that were near. "Wyjdź" is refused while in combat, and the next session starts at the character's start point.
